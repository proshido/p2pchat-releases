# p2pchat — Android Downloads

Compiled debug APKs for [p2pchat](https://github.com/proshido/p2pchat), an
anonymous, serverless-storage 1:1 P2P chat app for Android. This repo holds
**release binaries only** — no source code.

## Download

Grab the latest APK from the [Releases page](https://github.com/proshido/p2pchat-releases/releases/latest).

`latest.json` in this repo is machine-readable metadata the app itself uses
to check for updates.

Sideloaded app — Android will ask you to allow installs from this source
once. Source code is private; this repo exists solely to distribute builds.
